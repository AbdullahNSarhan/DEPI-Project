# DEPI-Project

## Malware Analysis & Detection Lab — RedLine Stealer

* Performed end-to-end **static and dynamic malware analysis** of a .NET-based RedLine Stealer sample, documenting execution flow, capabilities, and malicious behaviors.
* Reverse-engineered the sample using **Detect It Easy and dnSpy**, analyzing PE structure, .NET assemblies, resources, configuration, and relevant code paths.
* Built an isolated **Windows 10 + Kali Linux VirtualBox lab** and monitored malware activity through **Elastic Stack and Winlogbeat**.
* Investigated process, file, registry, and network activity and correlated telemetry to validate findings from static analysis.
* Extracted and documented **Indicators of Compromise (IOCs)** and mapped observed behaviors to **MITRE ATT&CK** techniques.
* Developed detection content and investigation queries to support **malware detection and threat hunting**.
